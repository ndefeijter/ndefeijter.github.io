Privacyverklaring

NELIO Software Engineering (Niels de Feijter) is verantwoordelijk voor de verwerking van persoonsgegevens via deze website. Je bereikt me op info@nelio.se.

Wat deze website niet doet

Deze website gebruikt geen cookies, geen analytics en geen trackers. De lettertypen staan op deze website zelf, dus je browser maakt daarvoor geen verbinding met andere partijen.

Hosting

De website wordt gehost door GitHub Pages (GitHub, Inc.). Bij elk bezoek verwerkt GitHub technische gegevens zoals je IP-adres, om de website te leveren en te beveiligen. Zie de privacyverklaring van GitHub voor details.

Contact

Als je me mailt, gebruik ik je naam, e-mailadres en bericht alleen om je vraag te beantwoorden en een eventuele samenwerking voor te bereiden. Ik bewaar die gegevens niet langer dan daarvoor nodig is. Plan je een kennismaking via de boekingspagina, dan verwerkt Google je naam, e-mailadres en het gekozen tijdstip in Google Agenda en Google Meet. Het contactformulier op deze website is nog niet actief en verstuurt geen gegevens.

Je rechten

Je kunt me vragen welke gegevens ik van je heb, en vragen om ze te corrigeren of te verwijderen. Mail daarvoor naar info@nelio.se. Ben je niet tevreden over hoe ik met je gegevens omga, dan kun je een klacht indienen bij de Autoriteit Persoonsgegevens.
